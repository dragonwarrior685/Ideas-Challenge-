# Deploy Moana Pathways to GitHub Pages - Easy Setup Guide\n\n## 🚀 One-Time Setup (5 minutes)\n\n### Step 1: Enable GitHub Pages in Your Repository\n\n1. Go to: **https://github.com/dragonwarrior685/Ideas-Challenge-/settings/pages**\n\n2. Under **\"Source\"**, select:\n   - Branch: **main**\n   - Folder: **/root** (or leave default)\n   - Click **Save**\n\n3. Wait 1-2 minutes for GitHub to build\n\n### Step 2: Build & Deploy Locally\n\nRun these commands in your terminal:\n\n```bash\n# Make sure you're in the project folder\ncd Ideas-Challenge-\n\n# Build the game for deployment\nnpm run build\n\n# This creates a 'dist' folder ready to deploy\n```\n\n### Step 3: Deploy to GitHub Pages\n\n**Option A: Using Git (Recommended)**\n\n```bash\n# Install gh-pages package\nnpm install --save-dev gh-pages\n\n# Add deployment script to package.json (already done)\n# Then deploy:\nnpm run deploy\n```\n\n**Option B: Manual Upload**\n\n1. Go to: https://github.com/dragonwarrior685/Ideas-Challenge-\n2. Click **Actions** tab\n3. You should see a workflow (if not, create one manually)\n4. It will auto-deploy when you push to main\n\n---\n\n## 🎮 Your Game Will Be Live At:\n\n```\nhttps://dragonwarrior685.github.io/Ideas-Challenge-/\n```\n\n✅ **Share this link with anyone to play!**\n\n---\n\n## ⚡ Quick Deploy Commands\n\nOnce set up, deploy future updates with:\n\n```bash\n# Make changes to code\n# Then:\nnpm run build\nnpm run deploy\n\n# Done!
