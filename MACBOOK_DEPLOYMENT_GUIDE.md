# 🎮 Complete MacBook Guide - Play Live Game in Browser\n\n## Step 1️⃣: Download Your Game Code\n\n### What to do:\n1. Go to this link in your browser:\n   ```\n   https://github.com/dragonwarrior685/Ideas-Challenge-\n   ```\n\n2. Click the green **CODE** button (top right)\n   ![Screenshot would show green CODE button]\n\n3. Click **Download ZIP**\n   ![Screenshot would show Download ZIP option]\n\n4. Wait for the download (takes 10-30 seconds)\n\n5. You'll see a file called `Ideas-Challenge--main.zip` in your Downloads\n\n---\n\n## Step 2️⃣: Unzip the Downloaded File\n\n### What to do:\n1. Open **Finder** (click the face icon in dock)\n\n2. Click **Downloads** (left sidebar)\n\n3. You'll see `Ideas-Challenge--main.zip`\n\n4. **Double-click** it to unzip\n\n5. Wait 5 seconds... a folder called `Ideas-Challenge--main` appears\n\n6. Rename it to `Ideas-Challenge-` (remove the `--main` part)\n   - Right-click → Rename\n   - Delete `--main` and press Enter\n\n---\n\n## Step 3️⃣: Open Terminal on Your Mac\n\n### What to do:\n1. Press **Cmd + Space** (at the same time)\n\n2. Type: `terminal`\n\n3. Press **Enter**\n\n4. Terminal window opens (black/gray box)\n\n---\n\n## Step 4️⃣: Go to Your Game Folder\n\n### In Terminal, type:\n```bash\ncd Downloads/Ideas-Challenge-\n```\n\nThen press **Enter**\n\n✅ You should see something like:\n```\ngracesenio@MacBook Ideas-Challenge- %\n```\n\nIf you see that, keep going! ✅\n\n---\n\n## Step 5️⃣: Install Dependencies (One-Time Setup)\n\n### In Terminal, type:\n```bash\nnpm install\n```\n\nPress **Enter**\n\n⏳ **Wait 2-3 minutes** - lots of text will scroll\n\n✅ When done, you'll see:\n```\nup to date in X.XXs\n```\n\n---\n\n## Step 6️⃣: Deploy Your Game Online\n\n### First, install deployment tool:\n```bash\nnpm install --save-dev gh-pages\n```\n\nPress **Enter**\n\n⏳ **Wait 1 minute**\n\n---\n\n### Then, build your game:\n```bash\nnpm run build\n```\n\nPress **Enter**\n\n⏳ **Wait 1 minute**\n\n---\n\n### Finally, deploy it:\n```bash\nnpm run deploy\n```\n\nPress **Enter**\n\n⏳ **Wait 30 seconds**\n\n✅ You should see:\n```\nPublished to gh-pages\n```\n\n---\n\n## Step 7️⃣: Play Your Game! 🎮\n\n### Wait 2-3 minutes, then:\n\n1. **Open your browser** (Chrome, Safari, etc.)\n\n2. Go to this URL:\n   ```\n   https://dragonwarrior685.github.io/Ideas-Challenge-/\n   ```\n\n3. Press **Enter**\n\n4. You should see **MOANA PATHWAYS** menu! 🌺\n\n---\n\n## 🎯 You're Now Ready to Play!\n\n### Click on:\n- **PLAY GAME** - Runner game (avoid red, collect gold)\n- **FIND MENTOR** - Connect with mentors\n- **CAREER QUIZ** - Discover your career path\n\n---\n\n## ❓ If Something Goes Wrong\n\n### Error: \"command not found: npm\"\n→ You need to install Node.js first\n1.
