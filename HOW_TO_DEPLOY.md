# 🚀 How to Deploy Your Game - Step by Step\n\n## DEPLOYMENT IN 4 SIMPLE STEPS\n\n### Step 1: Open Your Terminal\n\n**Windows:**\n- Press `Windows Key + R`\n- Type `cmd` and press Enter\n\n**Mac:**\n- Press `Cmd + Space`\n- Type `terminal` and press Enter\n\n**Linux:**\n- Press `Ctrl + Alt + T`\n\n---\n\n### Step 2: Go to Your Game Folder\n\nIn terminal, type:\n```bash\ncd Ideas-Challenge-\n```\n\n*(Or wherever you saved the folder)*\n\n---\n\n### Step 3: Run These Commands (One at a Time)\n\n**Command 1:** Install deployment tool\n```bash\nnpm install --save-dev gh-pages\n```\n⏳ Wait for it to finish (1-2 minutes)\n\n**Command 2:** Build your game\n```bash\nnpm run build\n```\n⏳ Wait for it to finish (30 seconds - 1 minute)\n\n**Command 3:** Deploy online\n```bash\nnpm run deploy\n```\n⏳ Wait for it to finish (30 seconds)\n\n---\n\n### Step 4: Check if It's Live\n\n1. Wait 2-3 minutes\n2. Go to:\n```\nhttps://dragonwarrior685.github.io/Ideas-Challenge-/\n```\n3. If you see the **Moana Pathways menu**, it worked! 🎉\n\n---\n\n## ✅ What Each Command Does\n\n| Command | What It Does |\n|---------|-------------|\n| `npm install --save-dev gh-pages` | Downloads the tool to deploy |\n| `npm run build` | Creates the game files ready to upload |\n| `npm run deploy` | Uploads game to GitHub Pages (online) |\n\n---\n\n## 🎮 Your Game Link\n\n```\nhttps://dragonwarrior685.github.io/Ideas-Challenge-/\n```\n\n**Share this with anyone to play!**\n\n---\n\n## ❓ Troubleshooting\n\n### \"Command not found: npm\"\n→ Node.js didn't install.
